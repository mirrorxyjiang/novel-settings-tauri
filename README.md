# 小说设定管理工具 · Novel Settings

一款给小说作者自己用的**创作设定管理桌面应用**：以「书籍」为单位，管理人物关系、地图、大纲、时间线等设定资料，每个模块下可以自由新建页面，页面可以是**绘图区**（画布、图标、连线、背景图层）或**文字区**（富文本笔记）。

基于 [Tauri 2](https://tauri.app) + React 构建，数据以 JSON 文件的形式存在本地磁盘上，存储目录可以指向任意云盘同步文件夹（iCloud云盘 / OneDrive / 坚果云……），从而实现多台电脑之间的设定数据迁移，不依赖任何账号或服务器。

> 这是个人向的创作工具，没有多人协作、没有后端服务，你的数据只存在你自己的电脑（和你自己选的云盘）里。

## 功能一览

**书籍 / 模块 / 页面结构**
- 每本书固定包含「人物关系」「地图」「大纲」「时间线」四大模块，可以另外新建自定义模块
- 书籍、模块、绘图页/文字页都支持重命名（书籍在书库首页或侧边栏点 ✎；页面在侧边栏双击名字，或直接在页面顶部的标题框里改）
- 页面支持**任意层级的子页面**——一个页面下面还可以再挂子页面，适合把复杂设定拆成主页 + 细节页

**文字区**
- 基础富文本：加粗、斜体、下划线、有序/无序列表、标题
- 输入停顿 1 秒会自动同步保存，失焦时也会立即保存；页面顶部另外有「💾 立即保存」按钮，随时手动保存不用等

**绘图区**
- 矩形 / 圆形 / 直线 / 箭头 / 文本框，拖拽创建，边框颜色·粗细·实线虚线点线、填充颜色·透明度（可调到完全透明）都能自定义
- 16 个内置基础图标可直接点选放置；也支持导入自己的图片作为图标
- **背景图层**（地图模块常用）：导入一张底图作为背景，可拖动/缩放，标注完成后可以锁定防止误触
- 画布支持**缩放**（工具栏 +/− 按钮，或 Ctrl/Cmd + 滚轮）和**抓手拖动平移**（工具栏「抓手」按钮，或按住空格键临时切换）
- 点击图标/图形可添加备注；连线可拖动端点、可加文字标签
- 文本框支持自定义文字颜色和加粗

**存储与迁移**
- 每本书是独立的 JSON 文件，导入的图片单独存成文件（不再内嵌成 base64，避免书籍文件越滚越大、卡顿）
- 书库首页可以随时查看/更改当前存储目录——指向云盘同步文件夹，换电脑后重新指向同一个文件夹即可迁移全部数据
- 删除是软删除，文件会被移到 `books/.trash/`，误删了可以自己从磁盘找回

## 技术栈

- [Tauri 2](https://tauri.app)（Rust 外壳 + 系统 WebView）
- React 18 + Vite
- 纯 SVG 手写画布引擎（没有依赖 Konva/Fabric 之类的第三方绘图库）
- 本地文件系统存储，无数据库、无后端

## 快速开始

### 前置环境

1. **Node.js**（建议 18+）与 npm
2. **Rust 工具链**：<https://www.rust-lang.org/tools/install>，装完新开一个终端窗口执行 `rustc --version` 确认装好了
3. **Tauri 所需的系统依赖**（每台开发机只需配置一次）：
   - macOS：`xcode-select --install`
   - Windows：Microsoft C++ Build Tools（装 Rust 时选"Quick install"会自动引导安装）、WebView2（Win10/11 通常已自带）
   - Linux：`webkit2gtk`、`libssl-dev` 等，具体包名因发行版而异，参见 [Tauri 官方文档](https://tauri.app/start/prerequisites/)

### 安装与开发

```bash
git clone <你的仓库地址>
cd novel-settings-tauri
npm install
npm run tauri dev
```

首次运行会编译 Rust 部分，耗时可能几分钟，之后会自动弹出桌面窗口。

### 打包发布

```bash
npm run tauri build
```

打包前建议：
1. 用正式图标替换 `src-tauri/icons/` 下的占位图标（`npx tauri icon 你的图标.png` 可以自动生成各平台所需的全部尺寸）
2. 把 `src-tauri/tauri.conf.json` 里的 `identifier` 改成你自己的唯一标识（反转域名风格，如 `com.yourname.novelsettings`）

## 数据存储结构

```
<数据存储目录>/
└─ books/
    ├─ 8f3ka2mZ.json            一本书 = 一个 JSON 文件，文件名即书籍 id
    ├─ 8f3ka2mZ-assets/         这本书导入的图片（图标 / 背景图）单独存在这里
    │   └─ 1731000000123.png
    ├─ pQ92xLrT.json
    └─ .trash/                   软删除的书籍会被移动到这里，而不是直接抹除
```

`config.json`（记录当前生效的存储目录路径）单独存放在系统级应用配置目录，不在上面这个数据文件夹里。

**跨设备迁移方法**：在新电脑上安装本应用 → 打开后在书库首页点击"更改存储位置" → 选择云盘同步文件夹里你的数据目录，应用会立即从该目录重新读取书籍列表。只要两台电脑上这个文件夹路径都由同一个云盘客户端在后台同步，数据就能保持一致。注意不要在两台电脑上"同时"编辑同一本书，云盘同步可能产生冲突文件，建议单线程使用。

## 项目结构

```
novel-settings-tauri/
├─ public/                   静态资源（favicon 等），vite 原样拷贝到构建产物
├─ index.html                前端入口 HTML
├─ package.json
├─ vite.config.js
├─ src/                      前端源码
│   ├─ main.jsx               React 挂载入口
│   ├─ App.jsx                 核心业务组件：书库首页 / 侧边栏 / 绘图区 / 文字区
│   ├─ ErrorBoundary.jsx        全局错误边界，渲染异常时给出可恢复的提示页而不是白屏
│   └─ store.js                前端与 Rust 后端的存储桥接层（封装 invoke 调用）
└─ src-tauri/                 Rust 后端
    ├─ Cargo.toml
    ├─ build.rs
    ├─ tauri.conf.json         应用窗口、打包配置
    ├─ capabilities/
    │   └─ default.json        Tauri v2 权限声明
    ├─ icons/                  应用图标
    └─ src/
        ├─ main.rs             程序入口
        └─ lib.rs               核心命令：本地文件存储、图片素材、目录选择、配置管理
```
